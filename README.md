# 💰 App Reajuste Salarial

Aplicativo Android desenvolvido para calcular o novo salário de um funcionário com base em percentuais de reajuste (40%, 45% ou 50%).

---

## 📱 Funcionalidades

- Entrada do salário atual
- Escolha do percentual de aumento com `RadioButtons`
- Cálculo automático do novo salário
- Interface com cores personalizadas e amigável
- Layout responsivo com `ConstraintLayout`
- Separação de valores reutilizáveis em `AppValues.xml`

---
